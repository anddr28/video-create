# АЛЬФАХИМИЯ — ролик «Этиловый спирт 96%» (9:16, 10 с)

Пакет для генерации ролика в видеомодели (Veo 3 / Kling 2.x / Sora 2 / Runway Gen-4).

## Файлы

| Файл | Назначение |
|---|---|
| `assets/poster_reference.jpg` | исходный постер (только как образец внешнего вида) |
| `assets/bottle_reference.png` | вырезанная бутылка без графики постера: загружать как reference / первый кадр |
| `prompts/full_10s.md` | один промпт на весь ролик (для моделей, которые умеют 10 с одним куском) |
| `prompts/shots.md` | три отдельных промпта по планам + монтаж и озвучка (самый надёжный путь) |
| `prompts/negative.txt` | negative prompt |

## Почему лучше по планам

1. **Текст этикетки.** Видеомодели часто искажают кириллицу («АЛФАХИМИЯ», «ЭТИЛОВЫИ», «69%»).
   Лучше всего работает image-to-video: стартовый кадр с правильной бутылкой
   (`assets/bottle_reference.png` вставить в сцену в любом генераторе изображений), а дальше
   анимировать его с маленьким движением камеры. Если буквы всё равно плывут, этикетку
   накладывают трекингом в монтаже (After Effects / DaVinci, planar tracker).
2. **Длительность.** Veo 3 даёт 8 с за проход, Kling — 5/10 с. Три клипа по 3–4 с проще
   контролировать, а склейки по вспышке и растворения делаются в монтаже.
3. **Голос.** Русская озвучка внутри генерации нестабильна по таймингу. Надёжнее записать
   VO отдельно (TTS или диктор) и подложить: речь 0–9 с, 9–10 с тишина.

## Тайминг озвучки

| Время | Текст |
|---|---|
| 0.2–2.8 с | «Этиловый спирт девяносто шесть процентов — топливо для горелок.» |
| 3.3–5.6 с | «Чистое и стабильное пламя.» |
| 6.2–8.9 с | «Без запаха и копоти. Жми, чтобы заказать!» |
| 9.0–10.0 с | тишина, только треск пламени / лёгкий эмбиент |
